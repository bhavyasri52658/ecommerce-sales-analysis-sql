# E-commerce Sales Analysis Using SQL

## Project Overview
This project analyses e-commerce sales data using PostgreSQL to identify sales trends, customer spending patterns, product performance, and order cancellation rates. The goal is to transform raw order and product data into meaningful business insights that support data-driven decision-making.

## Tools and Technologies
- **Database:** PostgreSQL
- **Language:** SQL
- **Concepts:** JOIN, GROUP BY, ORDER BY, aggregate functions, CASE WHEN, subqueries, LEFT JOIN, window functions, and Common Table Expressions concepts.

## Dataset
The project uses two relational tables:

- **Products:** Product ID, product name, category, and price.
- **Orders:** Order ID, customer name, product ID, quantity, order date, and order status.

## Key Analysis Performed
- Calculated total revenue from delivered orders.
- Identified top-performing products by revenue and units sold.
- Compared revenue across product categories.
- Analysed customer spending patterns.
- Calculated order cancellation rates.
- Evaluated daily sales performance.
- Calculated average delivered order value.
- Analysed category-wise revenue contribution.
- Created a daily running revenue total.
- Summarised key business performance indicators (KPIs).

## Key Findings
- **Total delivered revenue:** ₹11,900
- **Total orders:** 8
- **Delivered orders:** 7
- **Cancelled orders:** 1
- **Cancellation rate:** 12.50%
- **Top revenue-generating product:** Shoes — ₹4,500
- **Top revenue-generating category:** Footwear — ₹4,500
- **Highest-spending customer:** Ananya — ₹4,600
- **Average delivered order value:** ₹1,700

## Business Recommendations
- Investigate cancellation reasons to reduce lost sales.
- Monitor footwear performance and evaluate opportunities to increase sales.
- Analyse customer purchasing behaviour to develop targeted marketing campaigns.
- Track daily revenue and category performance to support inventory and sales planning.

## Skills Demonstrated
SQL querying, relational data analysis, data aggregation, business KPI calculation, revenue analysis, customer segmentation, and analytical problem-solving.

## Project Objective
This project demonstrates practical SQL skills for an entry-level Data Analyst role by answering business questions and presenting data-driven insights using a sample e-commerce dataset.

**Note:** This project uses a small sample dataset created for learning and demonstration. The findings are illustrative and do not represent actual business performance.
